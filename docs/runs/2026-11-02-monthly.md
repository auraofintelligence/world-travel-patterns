## Worth surfacing

- **A "due by" field for year-ahead.** Elections due within a year but without a polling date (PNG 2027, Marshall Islands by November 2027) have nowhere to go: events need a day. A `pending[]` list with `due_by` and `who_sets_it` would keep them visible on the site and in the queue. It has come up in three places this run (pg, mh, nf), which meets the three-place bar for a pattern change; proposed here rather than made, since it changes the pattern Codex also writes to.
- **Machine-checkable calendars.** GovHK publishes an iCal feed of gazetted holidays, and Hebcal has a JSON API. A small `moving_calendars.py` could write Easter, Lunar New Year and Jewish dates for every place each year, leaving only Islamic and local lunar dates to hand work.
- **ElectionGuide only lists to July 2027.** For places with no listed election, the note should say so rather than imply none exists. The records written today do.
- **Region code gaps.** Bonaire, Saba and Sint Eustatius (BQ), Chatham Islands (NZ-CIT) and Ascension, Saint Helena and Tristan da Cunha (SH) have holiday data but no matching place: worth adding as places, since each has its own administration.
- **Wording.** "No dated event in the window" reads better than leaving `events` empty with no note; worth adding to the pattern rules.
