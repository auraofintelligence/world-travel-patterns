# Private

Everything in this folder except this note is gitignored.

- `windows.json`: declared travel windows (copy `examples/windows.example.json`).
- `queue.json`: the window-aware queue written by `scripts/due.py`.
- `briefs/`: visitor briefs and window watch notes.
- `findings/`: vetting done during a window that isn't public yet. The weekly routine folds it into public records after the window closes, or straight away if the window says `"share": true`.
